# Import into Unity: Low-Poly Dungeon Props (40)

46 files, units: meters, Y-up (glTFast converts handedness).

## Steps

1. Install glTFast: Window > Package Manager > + > Add package by name > `com.unity.cloud.gltfast`.
2. Copy this folder to `Assets/Art/low-poly-dungeon/`. Each .glb imports as a prefab-like asset.
3. Files are in meters with the pivot already placed, so leave Scale Factor at 1.
4. Drag into the scene, add colliders (Box/Capsule for props, Mesh Collider only for static set dressing) and save as prefabs.
5. Mark non-moving set dressing Static (batching and baked GI).
