# Import into Roblox: Low-Poly Dungeon Props (40)

46 files, units: pre-scaled to studs (1 stud = 0.28 m).

## Steps

1. Studio > Home > Import 3D, select the .glb files.
2. Files are pre-scaled to studs (1 stud = 0.28 m). Compare against a 4-stud part or an R15 dummy after import.
3. Each mesh must stay under 20,000 triangles; textures above 1024 px are downscaled.
4. Set CollisionFidelity to Box or Hull for small props, and keep PreciseConvexDecomposition for walk-on surfaces only.
5. Anchor static props. Group variants under a Folder named after the asset.
